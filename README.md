# Flow-Rate-Measurement-of-Self-Compacting-Concrete-Using-Chirped-Fiber-Bragg-Grating-Sensors


This project presents a novel optical sensing system for real-time monitoring of Self-Compacting Concrete (SCC) flow using Chirped Fiber Bragg Grating (CFBG) sensors. Unlike conventional sensors, the CFBG-based system offers high strain and flow sensitivity, immunity to electromagnetic interference, and robust temperature compensation using a dual-FBG setup.

The system achieves:

Strain sensitivity: 2 pm/µε

Flow rate sensitivity: 0.006454 nm/(m³/s)

Noise reduction: Via a Hybrid Multi-Resolution Noise Suppression with Peak Preservation (HMNS-PP) algorithm

Temperature compensation: Using a dual-FBG approach to isolate strain signals

Key applications include real-time structural health monitoring, segregation detection, and SCC mix optimization in construction.
